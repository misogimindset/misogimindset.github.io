# MisogiMindset pages

The Support & Feedback page and privacy policy for the MisogiMindset iPhone app, published with GitHub Pages:

- Support & Feedback: https://misogimindset.github.io/
- Privacy policy: https://misogimindset.github.io/privacy.html

Dark only. Plain HTML and CSS with no scripts, fonts or other outside resources. `.nojekyll` makes GitHub publish the files as they are. After changing `style.css`, bump the `?v=` number on its link in both pages so browsers fetch the new copy.
